# Публичный интерфейс библиотеки `autumn-openfeature`

## Классы

* [НастройкиФлагов](Классы/НастройкиФлагов.md)
* [ФабрикаФлагов](Классы/ФабрикаФлагов.md)

## Сводка

| Единица | Метод | Возвращает |
|---|---|---|
| `НастройкиФлагов` | `Провайдер()` | `Строка` |
| `НастройкиФлагов` | `ПутьКФайлу()` | `Строка` |
| `НастройкиФлагов` | `Домен()` | `Строка` |
| `ФабрикаФлагов` | `FeatureClient()` | `FeatureClient` |

## Что попадает в контейнер

| Имя желудя | Тип | Откуда |
|---|---|---|
| `НастройкиФлагов` | `&Желудь` | Секция `openfeature` файла `autumn-properties.json` |
| `ФабрикаФлагов` | `&Дуб` | Конфигурация стартера |
| `FeatureClient` | `&Завязь` | `ФабрикаФлагов.FeatureClient()` |

Прикладной код объявляет зависимость только от `FeatureClient` - остальное поднимает контейнер.

```bsl
&Пластилин Перем FeatureClient;
```

Тип клиента описан в библиотеке [openfeature](https://github.com/yellow-hammer/openfeature): методы
`ПолучитьЛогическое`, `ПолучитьСтроку`, `ПолучитьЧисло`, `ПолучитьОбъект` и их варианты `...СДеталями`.
