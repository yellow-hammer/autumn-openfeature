# Класс `НастройкиФлагов`

Желудь с прочитанной секцией `openfeature` файла `autumn-properties.json`. Значения читаются детальками при создании
объекта, поэтому дальше настройки неизменны.

Исходник: `src/Классы/НастройкиФлагов.os`

## Детальки

| Деталька | По умолчанию | Поле |
|---|---|---|
| `openfeature.Провайдер` | `memory` | `Провайдер()` |
| `openfeature.ПутьКФайлу` | `flags.json` | `ПутьКФайлу()` |
| `openfeature.Домен` | `""` | `Домен()` |

Значение провайдера приводится к нижнему регистру и очищается от пробелов: в настройках допустимы `JSON`, ` json `
и `json`.

## Методы

| Метод | Возвращает | Назначение |
|---|---|---|
| [`Провайдер`](#провайдер) | `Строка` | Вид провайдера |
| [`ПутьКФайлу`](#путькфайлу) | `Строка` | Файл флагов для провайдера `json` |
| [`Домен`](#домен) | `Строка` | Домен клиента |

## Провайдер

```bsl
Функция Провайдер() Экспорт
```

Вид провайдера: `json`, `memory` или `none`.

**Возвращаемое значение**

`Строка` - идентификатор провайдера в нижнем регистре.

Неизвестное значение проверкой не отсекается: [`ФабрикаФлагов`](ФабрикаФлагов.md) оставит провайдер-заглушку,
как при `none`.

## ПутьКФайлу

```bsl
Функция ПутьКФайлу() Экспорт
```

Путь к файлу с описанием флагов. Используется только провайдером `json`.

**Возвращаемое значение**

`Строка` - путь к файлу.

## Домен

```bsl
Функция Домен() Экспорт
```

Домен, с которым создаётся клиент оценки.

**Возвращаемое значение**

`Строка` - имя домена либо пустая строка. Пустая строка означает клиента без домена.
