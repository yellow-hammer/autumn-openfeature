# Документация библиотеки `autumn-openfeature`

Стартер, который поднимает провайдера [OpenFeature](https://openfeature.dev) по настройкам приложения и отдаёт клиента
оценки флагов как обычную зависимость [autumn](https://github.com/autumn-library/autumn).

## Назначение

Библиотека [openfeature](https://github.com/yellow-hammer/openfeature) даёт стандартный API флагов, но требует ручной
регистрации провайдера при старте приложения. Стартер убирает эту работу: источник флагов описывается секцией в
`autumn-properties.json`, а прикладной компонент объявляет `&Пластилин Перем FeatureClient` и сразу работает с флагами.

Сменить источник флагов - правка настроек, а не кода. Прикладной код не упоминает ни `УстановитьПровайдер`,
ни путь к файлу флагов.

## Установка

```
opm install autumn-openfeature
```

Зависимости времени выполнения: `autumn`, `openfeature`.

## Быстрый старт

`autumn-properties.json`:

```json
{
  "openfeature": {
    "Провайдер": "json",
    "ПутьКФайлу": "flags.json",
    "Домен": "магазин"
  }
}
```

Прикладной компонент:

```bsl
&Пластилин Перем FeatureClient;

&Желудь
Процедура ПриСозданииОбъекта()
КонецПроцедуры

Процедура ОформитьЗаказ() Экспорт

	Контекст = Новый EvaluationContext(ИдентификаторПользователя, Новый Структура("plan", "pro"));

	Если FeatureClient.ПолучитьЛогическое("new-checkout", Ложь, Контекст) Тогда
		НоваяКорзина();
	Иначе
		СтараяКорзина();
	КонецЕсли;

КонецПроцедуры
```

## Настройки

Секция `openfeature` в `autumn-properties.json`:

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `Провайдер` | `memory` | `json` - флаги из файла, `memory` - набор в памяти, `none` - только значения по умолчанию |
| `ПутьКФайлу` | `flags.json` | Файл с описанием флагов для провайдера `json` |
| `Домен` | `""` | Домен, с которым создаётся клиент; попадает в метаданные |

Значение `none` оставляет провайдер-заглушку `NoopProvider`. Это рабочий режим для тестов и для стендов с отключёнными
флагами: приложение получает переданные значения по умолчанию и не зависит от внешнего источника.

Формат файла флагов описан в [README библиотеки openfeature](https://github.com/yellow-hammer/openfeature#описание-флагов).

## Момент регистрации провайдера

Провайдер регистрируется при первом обращении к завязи `FeatureClient`, а не в конструкторе фабрики: поле
`&Пластилин НастройкиФлагов` к моменту конструктора ещё не заполнено, а порядок инициализации компонентов autumn
не гарантирован. Повторные обращения провайдера не меняют - проверяется имя уже установленного.
